# КофейныйМастер

## Описание

"КофейныйМастер" — это WPF-приложение для создания, сохранения и ведения истории приготовления кофе с поддержкой достижений, профиля пользователя, анимаций и работы с внешними источниками данных (JSON). Проект реализован по паттерну MVVM.

## Основные возможности
- Создание кофе из набора ингредиентов и модификаторов
- Сохранение и удаление пользовательских рецептов
- История приготовленных напитков
- Система достижений
- Профиль пользователя (уровень, опыт, баланс, статистика)
- Анимация появления результата
- Сохранение и загрузка истории и рецептов в/из JSON
- Мультиокна (основное окно + окно профиля)
- Полная поддержка MVVM и Data Binding

## Запуск
1. Откройте решение в Visual Studio.
2. Соберите и запустите проект WpfApp3.
3. Для работы с JSON-файлами (история, рецепты) не требуется дополнительных библиотек.

## Архитектура
- **MVVM**: вся бизнес-логика вынесена во ViewModel, UI работает через Data Binding.
- **Models**: UserProfile, Recipe, Ingredient, Achievement, CoffeeHistoryItem.
- **ViewModels**: MainViewModel, ProfileViewModel.
- **Views**: MainWindow, ProfileWindow.
- **Converters**: IngredientCheckedConverter для биндинга чекбоксов.

## Работа с внешними источниками данных
- История и рецепты сохраняются и загружаются в/из файлов `coffee_history.json` и `recipes.json`.
- Для сохранения/загрузки используйте соответствующие кнопки в нижней панели.
